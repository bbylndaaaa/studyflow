# StudyFlow

Aplikasi web untuk mahasiswa: tugas (dengan minggu kuliah & tenggat), materi, mata kuliah,
jadwal mingguan, folder berkas, dan timer fokus.

- Akun dan data aplikasi, termasuk isi lampiran, disimpan di MySQL.
- Ekspor/Impor JSON mencakup data aplikasi dan metadata lampiran, bukan isi lampiran.
- Atur "Awal semester" di halaman Jadwal agar nomor minggu terhitung otomatis.
- Akun memakai MySQL untuk autentikasi; lihat [panduan XAMPP dan MySQL](PANDUAN-XAMPP-MYSQL.md).

## Menjalankan
    npm install
    npm run dev
Buka http://localhost:3000
